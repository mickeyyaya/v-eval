## How to add a memo

Name the file `YYYY-MM-DD-<topic>.md`. Start with the title, the research and access dates, the method and source count, and the labeling note. Cite original papers, official documentation, and repository files; record access dates for mutable claims; distinguish measured findings from inferences; list gaps you could not resolve. Add a row to the table above and, if the memo informed a decision, link it from the relevant record under [`docs/decisions/`](../decisions/README.md).

## Source register

[sources.md](sources.md) lists every external link cited anywhere in the repository, deduplicated and grouped by domain, with the documents that cite it. It is generated by `python tools/docs/vdocs.py register .` and verified in CI with `--check`; regenerate it whenever a document adds or removes a citation.
